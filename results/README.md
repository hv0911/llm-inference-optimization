# Results Directory

This directory contains benchmark and evaluation outputs generated by the pipeline scripts.

## Expected Contents (after running benchmarks)

```
results/
├── latency.csv              # Latency measurements across models
├── latency.json
├── throughput.csv            # Throughput measurements
├── throughput.json
├── memory.csv                # Memory usage data
├── memory.json
├── continuous_batching.csv   # Concurrency scaling data
├── continuous_batching.json
├── prefix_caching.csv        # Cold vs warm latency
├── prefix_caching.json
├── evaluation.csv            # lm-eval benchmark scores
├── evaluation.json
├── plots/                    # Generated charts (PNG)
│   ├── latency_comparison.png
│   ├── ttft_comparison.png
│   ├── throughput_comparison.png
│   ├── memory_comparison.png
│   ├── continuous_batching.png
│   └── prefix_caching.png
└── BENCHMARK_REPORT.md       # Auto-generated summary report
```

## Generating Results

```bash
# Run all benchmarks
python scripts/benchmark.py --models base,awq,gptq

# Run evaluation
python scripts/evaluate.py --models base,awq,gptq

# Analyze results
python notebooks/benchmark_analysis.py
```

> **Note**: CSV and JSON files in this directory are excluded from version control via `.gitignore` since they are regeneratable.
